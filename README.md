## 🚀 **Ключевые возможности**

### 🧠 **Интеллектуальный центр**
*   **Персонализированный AI-ассистент** (на базе GigaChat): приветствует по имени, помнит контекст диалога, предлагает продолжить прошлые темы.
*   **Голосовое сопровождение** (Yandex SpeechKit): озвучка диалогов и контента.
*   **Философские уведомления**: Каждый час — новая цитата великих мыслителей.

### 🌍 **Социальная активность**
*   **Лента новостей** (RSS Lenta.ru): всегда быть в курсе событий.
*   **Чат с пользователями**: Создавайте приватные и групповые беседы.
*   **Форум (Дискуссии)**: Публикуйте темы и обсуждайте их с сообществом.
*   **Интерактивная карта** (Yandex Maps API): Смотрите, где находятся другие пользователи, пишите им, добавляйте в друзья.
*   **Трекер перемещения**: Отслеживайте свои маршруты.

### 🎮 **Игровая галерея**
*   **Шахматы Online**: Игра с друзьями или случайным соперником. Партия сохраняется в любой момент.
*   **Тренировка памяти**: Запоминайте последовательности чисел.
*   **Быстрое сложение**: Арифметическая игра на время с уровнями сложности.
*   **Арканоид (Кирпичики)**: Классическая игра на ловкость.
*   **Пошаговая стратегия**: Проведите свою цивилизацию от Каменного века до эры роботов.
*   **ПВО**: Динамичная аркада с уклонением от ракет и боевыми миссиями.
*   **Угадай число**: Логическая игра с подсказками.

### 🛠 **Полезные инструменты (Всплывающее меню)**
*   **Анкета для ассистента**: Помогите AI лучше вас понять.
*   **Заметки**: Простой и удобный блокнот.
*   **Шагомер с мотивацией**: Считайте шаги, сравнивайте с другими, следите за прогрессом в виртуальных путешествиях (например, Москва — Сочи).
*   **Лотерея**: Участвуйте в розыгрышах с реальными призами.
*   **Тесты на эрудицию**: Проверьте знания в разных областях (Dota 2, наука, история и др.) и попадите в ТОП.
*   **Будильник и Таймер для бокса**: Настраиваемые интервалы для тренировок.
*   **Музыкальный поиск и плейлисты**: Создавайте свою фонотеку.

## 🛠 **Технологический стек**
*   **Язык**: Kotlin 100%
*   **База данных**: Firebase (Firestore, Realtime DB, Auth)
*   **Хранилище**: Yandex Cloud Storage (для изображений)
*   **Карты**: Yandex Maps SDK
*   **Голос**: Yandex SpeechKit
*   **ИИ-ассистент**: GigaChat API
*   **Уведомления**: OneSignal
*   **Новости**: Lenta.ru RSS парсинг
*   **Асинхронность**: Kotlin Coroutines, Flow
*   **DI**: Dagger Hilt / Koin
